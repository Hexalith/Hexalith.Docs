**Purpose**

This repository aims to standardize the documentation across all Hexalith modules. All documentation, especially the README files, must follow GitHub open-source best practices.

**About Hexalith**

Hexalith is a set of technical and business modules for managing enterprise workflows through a chatbot.

**Documentation principles**

- **Written for people.** Documentation must be clear and easy to read.
- **Concise at the top level.** The README and its table of contents give an overview only. Details go in dedicated sub-documents linked from the README.
- **Self-sufficient README.** The README must contain everything needed to understand the repository, without being too long.

**Quality and artifacts**

The README must link to the project's artifacts and quality indicators, for example:

- NuGet packages
- Quality metrics from services such as Coverity, SonarQube, or any other service considered relevant
