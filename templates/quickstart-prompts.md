# Quickstart prompts

Substitute the verified commands, prerequisites, first operation and expected output from the module's README. Put the resulting prompt directly below the reader's manual steps.

## Use the package

```text
Check the listed SDK and package feed.
Run the README's dotnet add package command in a fresh project.
Run the displayed sample and compare its result with the documented output.
Report the result or the first failing command.
```

## Run it

```text
Check the listed prerequisites and open the supported dev container.
Run the README's aspire run command and wait for healthy services.
Return the dashboard URL and run the documented first call.
Report its result.
```

## Use the tool

```text
Check the listed prerequisites, then run the README's tool install command.
Execute the first command with the documented arguments.
Compare its output with the example and report the result.
```

## Platform newcomer trial

```text
Check the listed prerequisites and open the supported clean environment.
Run the documented aspire run command and wait for healthy services.
Connect to the MCP server through Hexalith.McpCli.
Create a project in the run's tenant, list it back and show its identifier.
```

If credentials are required, add one line directing the reader to enter the value in the documented hidden prompt or ignored environment file and confirm completion. Keep secret values out of the session.
