# Hexalith.Docs

Hexalith Docs explains how the modules fit together and how to write and check their documentation.

## What it does and who it's for

Use this guide if you are choosing a Hexalith module, writing a package README or reviewing a documentation change. Each module maintains its own build and operations instructions.

## Quickstart

### Start here

- Learn how a tenant's command becomes an event and how modules run together in the [system overview](https://github.com/Hexalith/Hexalith.Docs/blob/main/docs/overview.md).
- Find a repository and its packages in the [module registry](https://github.com/Hexalith/Hexalith.Docs/blob/main/docs/module-registry.json).
- Prepare a README or package migration using the [documentation standard](https://github.com/Hexalith/Hexalith.Docs/blob/main/docs/documentation-standard.md).

## Documentation

From a local checkout, open `docs/overview.md` or `docs/documentation-standard.md`. Both can be read without downloading the referenced repositories.

## Part of Hexalith

Explore the libraries, business modules and platform that make up the project. [Hexalith on GitHub](https://github.com/Hexalith)

## Contributing
